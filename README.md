# lilya_brannd — الموقع + لوحة التحكم + الربط مع Noest Express

## الملفات
- `index.html` — الموقع (فيه السلة الجديدة بألوان/مقاسات/كمية لكل منتج)
- `admin.html` — لوحة التحكم (المنتجات، الطلبات، الأسعار، رموز مكاتب Noest)
- `netlify/functions/create-noest-order.js` — الدالة التي ترسل الطلبية تلقائيًا إلى Noest Express
- `netlify.toml` — إعداد Netlify ليعرف مكان الدالة

## خطوات التشغيل بعد رفع هذا المستودع وربطه بـ Netlify
1. من إعدادات موقع Netlify: **Site settings → Environment variables**، أضيفي:
   - `NOEST_API_TOKEN` = التوكن الخاص بحسابك في Noest
   - `NOEST_GUID` = الـ GUID الخاص بحسابك في Noest
2. أعيدي نشر الموقع (Trigger deploy) حتى تُقرأ القيم الجديدة.
3. من `admin.html` → "أسعار التوصيل"، املئي عمود "رمز مكتب Noest" لكل ولاية تستعملين فيها "توصيل إلى مكتب" (مثال: 19A لسطيف).
4. من صفحة "الطلبات"، جرّبي زر "تأكيد وإرسال لـ Noest" على طلبية واحدة، وتأكدي من ظهورها في لوحة Noest.

⚠️ ملاحظة: Noest لا تنشر توثيقًا عامًا لواجهتها البرمجية؛ إذا رفضت الطلب، انسخي رسالة الخطأ من لوحة التحكم وعدّلي حقول الطلب في `netlify/functions/create-noest-order.js` حسب التوثيق الذي أرسلته لك Noest عند فتح صلاحية API.
